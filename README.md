# Ice Cream Order Calculator

A fun interactive JavaScript project that calculates ice cream orders with customizable options.

**GitHub:** [github.com/Kodelack47/IceCream](https://github.com/Kodelack47/IceCream)

## Features

- Increment/decrement number of scoops
- Choose between cone or cup
- Select multiple toppings with pricing
- Real-time total calculation with tax
- Order summary display in console

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Select number of scoops
4. Choose container type (cone or cup)
5. Add toppings
6. Submit order and view results
